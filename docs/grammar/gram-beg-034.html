-아/어 있다 Resultant State ("Is/Has Been Left ~ed")

When an Action Is Finished, But Its Result Is Still There

GRAM-BEG-034 Elementary (TOPIK I) 20 min
LevelElementary (TOPIK I, 1–2급) — second item of this stage's Other Essential Expressions section
CategoryOther Essential Expressions > 5. Other Essential Expressions
Learning Goals ① Attach -아/어 있다 to a verb stem using the same bright/dark vowel rule as -아/어요 (GRAM-BEG-013) to describe a state that persists after an action is completed
② Contrast -고 있다 (GRAM-BEG-033, action in progress) with -아/어 있다 (result of a completed action persists) using common verb pairs
③ Recognize that -아/어 있다 typically only works with change-of-state/motion verbs (e.g. 앉다, 서다, 열리다), unlike -고 있다 which works freely with almost any action verb

1Concept Introduction — When the Result Sticks Around

In the last chapter, GRAM-BEG-033 taught you -고 있다 for an action happening right now — "is/am/are ~ing." This chapter's pattern, -아/어 있다, looks deceptively similar (it also ends in 있다) but does a different job: it describes a state that remains after an action has already finished. Instead of "in the middle of doing something," it means "already done, and still in that resulting condition."

The clearest way to see the difference is with a verb like 앉다 ("to sit down"). The sitting-down motion itself is brief — you don't stay "in the middle" of sitting down for long. But once you've sat down, you keep being seated for a while afterward. Korean has two separate tools for exactly this distinction, and this chapter is about the second one.

Preview
그는 의자에 앉아 있어요. ("He is sitting in the chair" — the sitting-down happened, and he's still seated.)
문이 열려 있어요. ("The door is open" — someone opened it, and it's still open now.)
Both describe a current state that resulted from a finished action — not an action happening right now.

2Concept Explanation

2.1 Formation: verb stem + -아/어 있다 (same vowel rule as -아/어요)

-아/어 있다 uses the exact same bright-vowel/dark-vowel rule you already learned for -아/어요 in GRAM-BEG-013: if the stem's last vowel is ㅏ or ㅗ (bright), attach -아 있다; otherwise, attach -어 있다. Just like with -아/어요, some combinations contract (merge into one syllable).

Verb stem + -아/어 있다
Verb (dictionary form)StemVowel type+ -아/어 있어요
앉다 (to sit down)앉 (ㅏ)Bright앉아 있어요
서다 (to stand up)서 (ㅓ)Dark, contracts서 있어요
눕다 (to lie down)누우 (ㅂ irregular)Dark누워 있어요
열리다 (to open, itself)열리 (ㅣ)Dark, contracts열려 있어요

Note 서다: the stem 서 already ends in ㅓ, so adding another 어 simply merges into the same syllable — 서 있어요, not 서어 있어요. This is the same contraction pattern you saw with 가다 → 가요 in GRAM-BEG-013.

Study Tip You're not learning a new vowel rule here — it's the exact -아/어 harmony from GRAM-BEG-013, just followed by 있다 instead of nothing. If you can already form -아/어요, you can already form the first half of -아/어 있다.
