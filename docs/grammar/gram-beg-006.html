에서 Location of Action & Starting Point

Where an Action Happens, or Where Movement Starts From

GRAM-BEG-006 Elementary (TOPIK I) 20 min
LevelElementary (TOPIK I, 1–2급)
CategoryParticles > 1. Particles
Learning Goals ① Use 에서 to mark the location where an ONGOING ACTION takes place (dynamic), contrasting explicitly with 에's static existence/destination use (GRAM-BEG-005)
② Use 에서 to mark the STARTING POINT of movement ("from")
③ Correctly choose between 에 (static existence/destination) and 에서 (location of action/starting point) given a sentence, avoiding the common learner confusion between the two

1Concept Introduction — Same Place, Different Particle

In GRAM-BEG-005 you learned 에 for two static jobs: marking where something simply exists ("be at") and marking the destination of a movement verb ("go to"). That chapter also previewed a puzzle: 학교에 있어요 ("[I] am at school") uses 에, but as soon as you describe an action happening at that same school, the particle changes. This chapter picks up exactly there.

에서 has two jobs of its own, and neither of them is "static existence." First, it marks the location where an ongoing action takes place — "at/in [place], doing something." Second, it marks the starting point of a movement — "from [place]." Both uses share one idea: 에서 always involves something happening or moving, never a thing simply sitting still.

Preview
학교에 있어요 ("[I] am at school" — existence, 에) vs. 학교에서 공부해요 ("[I] study at school" — action, 에서). Same place, same-looking English translation ("at school"), but two completely different Korean particles. Learning exactly when each one is correct is the whole point of this chapter.

2Concept Explanation

2.1 Use 1 — 에서 for the location of an ongoing action

When a sentence describes someone doing something (studying, eating, working, playing — any action verb), the place where that action happens is marked with 에서, not 에. Think of 에서 as answering the question "where does this activity take place?" rather than "where does this thing exist?"

에서 marking the location of an action
SentenceLiteral functionMeaning
학교에서 공부해요action location"[I] study AT school"
식당에서 먹어요action location"[I] eat at a restaurant"
회사에서 일해요action location"[I] work at a company"

Compare this directly with 학교에 있어요 ("[I] am at school"). That sentence has no action verb — 있다 ("to exist / be located") is a state, not an activity — so it keeps the static particle 에 from GRAM-BEG-005.

Study Tip Before choosing the particle, find the verb first. If the verb describes an action (study, eat, work, play, meet...), the place before it takes 에서. If the verb is 있다/없다 (existence) or a destination verb like 가다/오다 ("go/come"), the place takes 에 instead — exactly as you learned in GRAM-BEG-005.
