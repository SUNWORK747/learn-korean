1Concept Introduction — The Core of Every Syllable Block

In GRAM-PRE-001 you learned that every Hangul syllable block is built from up to three parts: an initial consonant (초성), a vowel (중성), and an optional final consonant (종성 / 받침). Of these three, the vowel is the only part every single block must have — even a syllable that "starts with a vowel sound," like 아 or 오, is written with a silent placeholder consonant ㅇ in the initial position, precisely so the vowel always has a block to sit in.

This means that before you can read or write a single Korean syllable, you need to know the vowels. In this chapter you will learn the 10 basic vowels, how they are built from the same Three Elements principle that shaped Hangul's design (previewed in GRAM-PRE-001 §2.3), and the 11 compound vowels (diphthongs) formed by combining two basic vowels into one sound.

Preview
나 (na, "I") and 너 (neo, "you") use the exact same consonant ㄴ — the only difference between them is one vowel, ㅏ versus ㅓ. Mixing up a vowel can completely change a word's meaning, so getting vowel sounds right is just as important as getting consonants right.

2Concept Explanation

2.1 Recap — The Three Elements (三才) principle

As introduced in GRAM-PRE-001, Hangul's vowels are built from three philosophical symbols representing Heaven, Earth, and Human. Every basic vowel is a combination of these three shapes.

The three basic elements
ElementSymbolOriginal Shape
Heaven (天)·A round dot — later simplified into a short stroke attached to a line
Earth (地)ㅡA flat horizontal line
Human (人)ㅣAn upright vertical line

Attaching the "Heaven" stroke to different sides of "Earth" (ㅡ) or "Human" (ㅣ) produces all 10 basic vowels.
