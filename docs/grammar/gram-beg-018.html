-(으)세요 Polite Command/Suggestion

The Grammar Behind Korean's Polite Commands

GRAM-BEG-018 Elementary (TOPIK I) 20 min
LevelElementary (TOPIK I, 1–2급)
CategorySentence-Final Endings > 2. Sentence-Final Endings
Learning Goals ① Attach -(으)세요 correctly by batchim — 세요 after a vowel-ending stem, 으세요 after a consonant-ending stem
② Use -(으)세요 to make polite commands, requests, and suggestions
③ Recognize -(으)세요 as the actual grammatical form behind the "command (명령문)" sentence type introduced conceptually back in GRAM-PRE-015

1Concept Introduction — The Command Type, Now With a Real Form

Back in GRAM-PRE-015, you learned that Korean sentences fall into four types by how they end: statements, questions, commands (명령문), and suggestions/propositive sentences (청유문). At the time, the command type was only illustrated conceptually — using an example like 학교에 가세요 ("Please go to school") to show what a command sounds like, without yet teaching the grammar that builds it. This chapter is where that grammar finally arrives: -(으)세요 is the actual ending used to form that sentence.

-(으)세요 attaches to a verb (or adjective) stem and turns it into a polite command, request, or suggestion — all in one friendly, respectful form. It is one of the most common endings you will hear in everyday Korean: from a doctor telling you to sit down, to a friend inviting you to come over, to the polite instructions printed on signs.

Preview
앉으세요. ("Please sit.") and 여기 오세요. ("Please come here.") both use -(으)세요 to turn a plain verb into a polite command — but notice one attaches 으세요 and the other just 세요. The rule behind that difference is the first thing you'll learn in this chapter.

2Concept Explanation

2.1 Choosing 세요 vs. 으세요 — the batchim rule

-(으)세요 attaches directly to a verb stem (the verb minus 다). Which form you use depends only on whether that stem ends in a consonant (받침) or a vowel — the same batchim logic you've already used for particles and other endings throughout this course.

-(으)세요 — attachment rule
Stem endingFormExampleMeaning
Vowel (받침 없음)세요가다 → 가세요"please go"
Consonant (받침 있음)으세요앉다 → 앉으세요"please sit"
Vowel (받침 없음)세요오다 → 오세요"please come"
Vowel (받침 없음)세요조심하다 → 조심하세요"please be careful"
Study Tip Same pattern as always: consonant-ending stem → the form starting with a consonant (으세요); vowel-ending stem → the form starting with a vowel (세요). This is the exact batchim rule you've used since GRAM-PRE-017 — only now it applies to a sentence-final ending instead of a particle.
