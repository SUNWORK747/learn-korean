-아/어서 Connective: Reason / Sequence

One Ending, Two Jobs — "Because" and "And Then"

GRAM-BEG-025 Elementary (TOPIK I) 25 min
LevelElementary (TOPIK I, 1–2급) — third item of this stage's Connective Endings section
CategoryConnective Endings > 3. Connective Endings (연결어미)
Learning Goals ① Attach -아/어서 to a verb or adjective stem using the same vowel-harmony rule as -아/어요 (bright vowel → -아서, other vowels → -어서, 하다 → 해서)
② Recognize the two core meanings of -아/어서: REASON ("because") when joining a cause and a result, and SEQUENCE ("and then") when joining two actions done in order by the same subject
③ Know that -아/어서 never takes -았/었- or -겠- directly before it, unlike -지만 — tense is shown only on the final verb

1Concept Introduction — "Because" and "And Then" in One Ending

You now know two connectives: -고 (neutral "and") and -지만 ("but"). This chapter introduces -아/어서, which does double duty — it can mean "because" (joining a cause and its result) or "and then" (joining two actions in the order they happened), depending on context. It's one of the most frequently used connectives in everyday Korean.

The good news: -아/어서 is built on a rule you already know. It attaches using the exact same vowel-harmony pattern as -아/어요 from GRAM-BEG-013 — bright vowel stems (ㅏ/ㅗ) take -아서, everything else takes -어서, and 하다 becomes 해서. If you can conjugate -아/어요, you can already half-conjugate -아/어서.

Preview
배가 고파서 밥을 먹었어요. ("I was hungry, so I ate rice." — REASON)
친구를 만나서 커피를 마셨어요. ("I met my friend and then drank coffee." — SEQUENCE)
Same ending, -아/어서, but the first clause type (a feeling/state vs. a deliberate action) tells you which meaning is at play — more on this in §2.2.

2Concept Explanation

2.1 Attaching -아/어서 — the same vowel harmony as -아/어요

-아/어서 attaches to a verb or adjective stem using the vowel-harmony rule from GRAM-BEG-013: if the stem's last vowel is ㅏ or ㅗ ("bright"), add -아서; for every other vowel ("dark"), add -어서; and 하다 verbs irregularly become 해서.

Stem + -아/어서, by vowel type
Word (dictionary form)StemVowel type+ -아/어서
가다 (to go)가bright (ㅏ)가서
앉다 (to sit)앉bright (ㅏ)앉아서
먹다 (to eat)먹dark (ㅓ)먹어서
고프다 (to be hungry)고프→고파dark, contracts고파서
공부하다 (to study)공부하하다 verb공부해서
Study Tip Reuse GRAM-BEG-013's rule exactly: ㅏ/ㅗ stem → -아서, everything else → -어서, 하다 → 해서. You're not learning a new attachment rule — you're applying an old one to a new ending.
