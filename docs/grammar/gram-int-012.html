-(으)ㄹ 것 같다 Vague Conjecture

Softening a Guess — "It Seems..." / "I Think It Will..."

② Correctly form the guess ending for verbs, adjectives, and 이다 across present, past, and future/vague time: -는 것 같다/-(으)ㄴ 것 같다/-(으)ㄹ 것 같다 for verbs; -(으)ㄴ 것 같다/-았/었을 것 같다/-(으)ㄹ 것 같다 for adjectives; 인 것 같다/이었을 것 같다/일 것 같다 for 이다
③ Distinguish the soft, hedged guess of -(으)ㄹ 것 같다 from the more definite statement of -(으)ㄹ 거예요 (GRAM-BEG-016), and use -것 같다 naturally to soften opinions and everyday guesses

1Concept Introduction — Softening a Guess, Present to Future

This is the first grammar point of a new subsection, "추측·의지 표현" (Conjecture & Intention Expressions), picking up right after GRAM-INT-011 -(으)ㄴ/는데도 wrapped up the Connective Endings Expansion section. -(으)ㄹ 것 같다 is arguably the single most common way Korean speakers hedge an opinion, describe the weather, or guess how someone else feels. Because 같다 itself is an adjective meaning "to be alike/similar," the whole pattern literally works out to something like "[it] is like [X will happen]" — a built-in softener that native speakers reach for constantly, in situations where an English speaker might just say "I think," "probably," or "it looks like."

Learners often first meet -(으)ㄹ 것 같다 as one fixed phrase for guessing about the future. But the piece right before 것 같다 actually changes shape depending on when the guessed event happens relative to now: -는 것 같다 for something happening right now, -(으)ㄴ 것 같다 for something that already happened (or, with adjectives, an ongoing state), and -(으)ㄹ 것 같다 for something that hasn't happened yet — or for a vaguer, more general impression. This chapter walks through all three, how 이다 fits in, and how -(으)ㄹ 것 같다 compares to the more definite -(으)ㄹ 거예요 you already know.

Preview
저는 오늘 좀 바쁠 것 같아요. ("I think I'll be a bit busy today.")
지금 밖에 비가 오는 것 같아요. ("It seems like it's raining outside right now.")
바쁠 것 같아요 is a vague, future guess about later today. 오는 것 같아요 is a present-tense guess based on evidence right now (maybe the sound of rain). Same underlying pattern — 것 같다 — but a different piece attached depending on "when."

2Concept Explanation

2.1 Formation overview: word type × guess time

-것 같다 always needs a modifier form in front of it, and that modifier changes with both the word type (verb / 있다·없다 / adjective / 이다) and the time being guessed about (present / past / future & vague). The table below is the full map — refer back to it as you go through the rest of this chapter.

-것 같다: modifier by word type and guess time
Word typePresent guessPast guessFuture / vague guess
Verb (동사)-는 것 같다-(으)ㄴ 것 같다-(으)ㄹ 것 같다
있다/없다-는 것 같다-았/었을 것 같다-(으)ㄹ 것 같다
Adjective (형용사)-(으)ㄴ 것 같다-았/었을 것 같다-(으)ㄹ 것 같다
이다/아니다인 것 같다/아닌 것 같다이었을/였을 것 같다일 것 같다/아닐 것 같다
Study Tip Just like -는데/-(으)ㄴ데 (GRAM-INT-001), 있다/없다 and "있다-compound" adjectives such as 맛있다 ("to be tasty") and 재미있다 ("to be fun") conjugate like verbs here too: 맛있는 것 같아요 (present), never 맛있은 것 같다.

3Examples

3.1 One pattern, three points in time

TimeKoreanMeaning
Present지금 사람이 많은 것 같아요."It seems like there are a lot of people right now."
Past아까는 사람이 많았을 것 같아요."There were probably a lot of people earlier."
Future/vague주말에는 사람이 많을 것 같아요."I think there'll be a lot of people on the weekend."
Future/vague (이다)저 사람은 사장님일 것 같아요."That person seems like they'd be the boss."
