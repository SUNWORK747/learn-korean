-(으)라고 하다 Reported Commands

Turning "Do this!" into "She told me to do this"

1Concept Introduction — Reporting What Someone Told You To Do

This is the fourth and final grammar point in the quotation series. You've already learned how to report statements (-다고 하다), questions (-냐고 하다), and suggestions (-자고 하다) indirectly. This chapter covers the last piece: reporting commands — things someone told you (or someone else) to do, or not to do. In English, this is the difference between the direct quote "Study more!" and the reported version "She told me to study more." Korean marks this shift with its own dedicated ending, -(으)라고 하다, attached directly to the verb stem.

One especially useful feature of -(으)라고 하다 is that it flattens speech-level differences. Whether the original command was blunt and plain ("가!"), polite ("가세요."), or friendly-casual ("가요."), all of them get reported using the exact same neutral form: 가라고 했어요. What matters in reported speech is no longer how politely the command was phrased — it's simply that a command happened. This chapter walks through the form rules, the negative command pattern -지 말라고 하다, the everyday spoken contraction -래요, and finally a full side-by-side summary of all four quotation types now that the series is complete.

Preview
엄마가 "숙제 먼저 해."라고 했어요. → 엄마가 숙제 먼저 하라고 했어요. ("Mom told me to do my homework first.")
선생님이 "늦지 마세요."라고 하셨어요. → 선생님이 늦지 말라고 하셨어요. ("The teacher told us not to be late.")
Notice both direct quotes — one plain ("해."), one polite ("마세요.") — collapse into the same neutral reported pattern: 하라고 했어요 for the affirmative command, 말라고 하셨어요 for the negative one. The original politeness level disappears once the command becomes someone else's report.

2Concept Explanation

2.1 Form: verb stem + -(으)라고 하다

-(으)라고 하다 attaches straight to the verb stem — not to the -아/어요 or -(으)세요 form. Which shape you use depends only on the stem's last sound: stems ending in a consonant take -으라고; stems ending in a vowel (or in the consonant ㄹ) take -라고. Because a command can only be given to an action, -(으)라고 하다 attaches only to verbs — adjectives and 이다 have no imperative form in Korean (you can't command someone to "be tall!"), so this pattern never applies to them.

Study Tip 하다 is a common trap: the reported command form is 하라고, never 해라고. Think of it as its own memorized irregular, the same way 하다's plain-style imperative is 해라, not 하아라. You may also see the honorific version -(으)시라고 하다 (e.g., 가시라고 하셨어요) when the reporter wants to keep showing respect toward the original speaker — but the plain stem without -시- is far more common in everyday reported speech.
